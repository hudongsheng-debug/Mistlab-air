## 数据和使用边界
这是科研与教学模拟工具，不是实时天气服务或已标定仪器。预设为合成条件，不能据此声称实测精度。各模块具有球形液滴、均匀介质、有限几何与统计采样等适用边界；强散射和稀有事件需要检查收敛、截断与独立参考。

## 常见问题

### 修改参数后为什么还看到旧图？
旧结果会标为待更新。请重新运行；完成后才替换上一份完整结果。

### 模拟结果能直接证明真实仪器精度吗？
不能。需要独立基准、收敛检查和与对应实测条件的验证。

### 为什么计算较久？
多次散射、更多光子和复杂几何会增加计算量。先用默认预设，再逐步增加规模。

### 文件选择器里找不到文件，或云文件无法读取？
先在系统“文件”中确认文件已完整下载、你有访问权限，且格式受本应用支持。重试时优先使用“我的 iPad”中的本地副本。扩展名相同不保证内部数据结构一致。

### 怎样报告问题？
说明你执行的操作、预期结果与实际结果，并提供不含敏感信息的截图。若需要样例，优先构造小型合成文件。没有源文件也可以先报告，我们会根据描述继续沟通。

## Quick start
- Choose a synthetic scenario on the home screen and create an experiment.
- Inspect medium, instrument, acquisition, and numerical parameters, then run.
- After computation, switch Workbench/Analysis Results and inspect optics, echoes, and clouds.
- Optionally import references or run additional diagnostics in Research tools.
- Return home to retain the local experiment, or save/export to a chosen file location.

## Data and scope
A research and educational simulation tool, not a live weather service or calibrated instrument. Presets are synthetic and do not establish measured accuracy. Modules have limits involving spherical droplets, uniform media, finite geometry, and statistical sampling. Strong scattering and rare events require convergence, truncation, and independent-reference checks.

## Saving and backups
Experiment parameters, imported size spectra/references/triangle meshes, completed-result caches, provenance records, and interface settings are stored locally. Users can import/export experiments and reports through Files. The app does not provide synchronization to a developer-operated server.
Export important work and retain source files before offloading or deleting the app. Offload App and Delete App can have different effects; check the actual system option on your iPad.

## Frequently asked questions

### Why do old plots remain after changing parameters?
Existing results are marked stale. Run again; the previous complete result is replaced only when the new run finishes.

### Do results establish real-instrument accuracy?
No. Use independent benchmarks, convergence checks, and validation against matching measured conditions.

### Why can computation take longer?
Multiple scattering, more photons, and complex geometry increase work. Start with default presets and increase scale gradually.

### A file is missing from the picker, or a cloud file will not open
In Files, confirm the file is fully downloaded, accessible, and in a supported format. Try a local copy under On My iPad. A matching filename extension does not guarantee a supported internal structure.

### How should I report a problem?
Describe the action, expected result, and actual result, with screenshots free of sensitive information. If an example is needed, prefer a small synthetic file. You may report the problem without a source file first; we can follow up from your description.
